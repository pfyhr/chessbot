An AlphaZero chess engine, built by measurement

The reinforcement-learning loop is built, proven on Connect4, and running on chess: ten hours of self-play takes a randomly initialised network to +531 Elo over its own starting point, and two search fixes add +160 on top of that. Most of the work has been finding out which measurements were lying.

01

How it is put together

Python drives the training loop, but Rust owns every board and every search tree. The boundary is crossed once per network batch, never once per node — a per-node crossing would cost more than the move generation it wraps.

The loop
Rust   step 256 games to their next leaf   ──┐
                                            │  one (N, C, H, W) array
Python one forward pass on MPS          ◄──┘
                                            │  logits + values
Rust   expand, back up, advance          ◄──┘
Because Gumbel search runs at a small simulation budget, each tree needs only one leaf per pass — concurrency comes from the number of games, not from forcing one tree to yield several. That removed virtual loss from the design entirely.

The search is Gumbel AlphaZero, not the 2017 PUCT formulation: root actions sampled without replacement, narrowed by sequential halving, and the improved policy — not visit counts — used as the training target. That is what makes 32 simulations per move viable where the original needed 800. Roughly a 25× throughput multiplier, and the difference between this being feasible on one machine and not.

Does it actually learn?

Forty generations of self-play, 256 games each, on one M2 Max. Three independent gates, all measured against ground truth rather than against the loss:

What worked

Proven-win propagation  +49 Elo

A terminal result is a fact, not a score. It was being min-max rescaled alongside value estimates, so a certain checkmate beat a confidently wrong guess by 0.13 — against Gumbel noise of σ ≈ 1.28. Now it short-circuits. This adds no chess knowledge: the rules already computed it.

Wider root search  +160 Elo

With 16 root actions and ~40 legal moves, the winning move is often never sampled. Doubling to 32 wins on fewer evaluations. Gumbel's premise is that considering few actions well beats considering many badly — which assumes a shortlist worth trusting. A better network may flip this back.

What didn’t

Not inventing draws  −70 Elo

Stopping a game at 200 plies and calling it a draw fabricates 36% of value labels. Raising the cap and dropping those labels fixed exactly that — and lost. The extra ~90 plies per game are a weak network shuffling in dead endgames, which is worse data than an invented label.

Opening preference  unexplained

Policy mass on the sound first moves swings rather than converges, and often ends below the 0.200 random baseline. Four hypotheses have failed: replay window, learning rate, value-target quality, and search width. There is no working theory.

Decisions made by measurement

Three choices that would have gone the other way on intuition. Each is a committed benchmark in the repository, not a recollection.

06

Three bugs worth the trouble

The improved policy was discarding its own prior

Connect4's centre metric was falling generation over generation — backwards for a game whose solved opening is the middle column. The sigma transform used raw Q values in [−1, 1] at unit scale, so the term reached ~60 against logits of order 1. The training target had collapsed to a near one-hot on argmax-Q, at a simulation budget where Q is mostly noise.

DeepMind's mctx min-max rescales completed-Q to [0, 1] and scales by 0.1. Neither detail is in the paper's main text, and the loop still trains without them — just badly. Same seed, generation 1: 

before   tactics 0.448   centre 0.083   vs-prev 0.515
after    tactics 0.347   centre 0.399   vs-prev 0.740

Move::to() returns the rook's square when castling

AlphaZero encodes castling as the king travelling two squares. Trusting shakmaty's to() would have filed every castle on a wrong, position-dependent plane — silently, since the encoding would still have been a valid bijection and every self-consistency test would still have passed.

PyO3 turns Vec<u8> into Python bytes

legal_moves() was handing back a bytestring, which then failed as a NumPy index. Changing the binding to u32 fixed it. Cheap to fix, invisible until something downstream indexed with it.

08

How far is one laptop from 5,000 TPUs?

AlphaZero played 44 million games in nine hours on 5,000 TPUs. That number is usually quoted to make a single machine sound hopeless. It is worth doing the arithmetic instead — and measuring rather than extrapolating, so the AlphaZero network was run on this M2 Max directly.

The per-chip gap is 13×, not 67,000×. One consumer laptop is within about an order of magnitude of a single first-generation TPU for this workload. Essentially the entire deficit is parallelism — hardware they had five thousand of and we have one of — rather than anything about the silicon.

And 271× of it is already bought back by algorithm choice, on the same machine: Gumbel search at 32 simulations instead of 800, and a network sized for the compute available. That turns 68.8 years into 93 days without touching the hardware.

At roughly 20,000 games an hour, a day of self-play is 475,000 games and a week is 3.3 million. So the binding constraint is no longer games-per-hour, which is now known — it is games-to-target, which is not. That is the honest uncertainty, and it is a much more interesting one to have.

What is not claimed

Connect4 tactical accuracy tops out at 0.583 on raw policy and 0.750 with search — not 1.0. Those are real misses against exact ground truth on positions with a forced win or a forced block. A 496k-parameter network at 32 simulations does not master Connect4 in fourteen minutes, and the gate for the phase was the loop learns, not Connect4 is solved.

The throughput figures above are inference only; real training competes for the same GPU, and 135 plies per game is an estimate. Chess remains a target of perhaps 1500–2000 Elo — but that is a budget conclusion, not a ceiling, and the budget turns out to be far less forbidding than the headline five thousand TPUs suggests.
