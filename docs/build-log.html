01

How it is put together

Python drives the training loop, but Rust owns every board and every search tree. The boundary is crossed once per network batch, never once per node — a per-node crossing would cost more than the move generation it wraps.

The loop
Rust   step 256 games to their next leaf   ──┐
                                            │  one (N, C, H, W) array
Python one forward pass on MPS          ◄──┘
                                            │  logits + values
Rust   expand, back up, advance          ◄──┘
Because Gumbel search runs at a small simulation budget, each tree needs only one leaf per pass — concurrency comes from the number of games, not from forcing one tree to yield several. That removed virtual loss from the design entirely.

The search is Gumbel AlphaZero, not the 2017 PUCT formulation: root actions sampled without replacement, narrowed by sequential halving, and the improved policy — not visit counts — used as the training target. That is what makes 32 simulations per move viable where the original needed 800. Roughly a 25× throughput multiplier, and the difference between this being feasible on one machine and not.

Does it actually learn?

Forty generations of self-play, 256 games each, on one M2 Max. Three independent gates, all measured against ground truth rather than against the loss:

centre preference score vs random tactical accuracy
The centre line is the one worth trusting most. Connect4 is solved: the first player wins only by taking the middle column. There is no opening book, no heuristic and no shaped reward anywhere in the loop — the network went from 0.193, below the 1-in-7 you would get by chance, to 0.999 unaided.

Decisions made by measurement

Three choices that would have gone the other way on intuition. Each is a committed benchmark in the repository, not a recollection.

Network throughput by batch size · MPS positions / second
Metal carries a fixed cost of roughly 2 ms per call, so a batch of one gets 482 positions per second against 24,411 at 512 — 50× from batching alone. A straightforward one-game-at-a-time search would leave the GPU 98% idle. This single number set the shape of the self-play driver.

05

Three bugs worth the trouble

The improved policy was discarding its own prior

Connect4's centre metric was falling generation over generation — backwards for a game whose solved opening is the middle column. The sigma transform used raw Q values in [−1, 1] at unit scale, so the term reached ~60 against logits of order 1. The training target had collapsed to a near one-hot on argmax-Q, at a simulation budget where Q is mostly noise.

DeepMind's mctx min-max rescales completed-Q to [0, 1] and scales by 0.1. Neither detail is in the paper's main text, and the loop still trains without them — just badly. Same seed, generation 1: 

before   tactics 0.448   centre 0.083   vs-prev 0.515
after    tactics 0.347   centre 0.399   vs-prev 0.740

Move::to() returns the rook's square when castling

AlphaZero encodes castling as the king travelling two squares. Trusting shakmaty's to() would have filed every castle on a wrong, position-dependent plane — silently, since the encoding would still have been a valid bijection and every self-consistency test would still have passed.

PyO3 turns Vec<u8> into Python bytes

legal_moves() was handing back a bytestring, which then failed as a NumPy index. Changing the binding to u32 fixed it. Cheap to fix, invisible until something downstream indexed with it.

Play it

Every generation is a saved checkpoint, so “how good was it after N generations?” is a question you answer by playing it. The staircase steps up when you win and back when you lose, so it finds your level in a handful of games instead of forty.

07

What is not claimed

Tactical accuracy tops out at 0.583 on raw policy and 0.750 with search — not 1.0. Those are genuine misses against exact ground truth on positions with a forced win or a forced block. A 496k-parameter network at 32 simulations does not master Connect4 in fourteen minutes.

The gate for this phase was the loop learns, not Connect4 is solved. And chess is several orders of magnitude away: AlphaZero used 5,000 TPUs for nine hours. The realistic target here is a bot that provably improves and reaches perhaps 1500–2000 Elo — not a Stockfish rival.
